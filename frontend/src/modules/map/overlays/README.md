HazardMotion adds decorative snow, surge ripples and hurricane wind streaks clipped to the server's Polygon/MultiPolygon hazard geometry. The motion is illustrative; particle direction and speed are not measured weather data.

Mount with the MapLibre map, current overlay FeatureCollection and the hazard-layer visibility. It paints on MapLibre render events driven by MapView's existing animation loop; it creates no second requestAnimationFrame loop. Geometry projection is cached until movement, resize or data changes. At most 300 particles are drawn, device-pixel ratio is capped at 2, and cleanup removes the canvas/listeners. Hidden tabs and reduced-motion users get the existing static hazard fills without particles. Help/work-order/text pins remain owned by ActivityLayers.
