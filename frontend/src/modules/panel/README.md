# Portfolio panel

Search, scenario hero, layer controls, overview, building list and building detail. Uses contract types and shared hooks. Works with pending/unavailable services without presenting mock finance as live data.

From frontend run `npm run build` and `npm run dev`. From Overview choose a top-five building, inspect its waterfall, and approve a proposed plan. In Buildings search a tenant, press Enter, switch sorts or clear the scenario-only filter. Test unavailable impact and plan services as well as success responses. The server must own risk, finance and plan calculations.
