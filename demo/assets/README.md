# City photos (optional)

The left-panel header shows a **blurred photo of the scenario's city** behind the title. Until you add photos, a
drawn skyline is shown instead (same blur), so the demo works without them.

Save as (JPG, roughly 1200×700):

| File | Scenario | Idea |
|---|---|---|
| `fort-myers.jpg` | Hurricane Ian | Fort Myers skyline / Caloosahatchee waterfront |
| `houston.jpg` | Hurricane Harvey | Downtown Houston skyline |
| `dallas.jpg` | Winter Storm Uri | Downtown Dallas skyline with Reunion Tower |

Use images you're allowed to use: your own photos, Unsplash/Pexels (free license), or Wikimedia Commons (check the
license and credit the author). Put credits in the pitch deck. After adding, run `python3 demo/build_single.py`.
