# Hero images (optional)

The left-panel header shows `assets/<scenario_id>.jpg` behind the scenario title (like the UTD map's photo header).
If a file is missing, a solid color is shown instead, so the demo works without them.

Use public-domain imagery (NOAA/NASA satellite images of each storm are public domain in the US). Save as:

| File | Suggested image |
|---|---|
| `harvey_houston.jpg` | NOAA GOES satellite image of Hurricane Harvey over Texas (Aug 2017) |
| `uri_dallas.jpg` | NOAA/NASA satellite image of snow cover over Texas, Feb 2021 |
| `ian_fort_myers.jpg` | NOAA GOES satellite image of Hurricane Ian at landfall (Sep 2022) |

About 1200×700 px, JPG. Credit "NOAA" in the pitch deck.
