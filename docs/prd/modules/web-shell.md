# Module: web-shell (`frontend/` scaffolding + `frontend/src/shared/`)

**Skills:** frontend, typescript, ui-design · **Read also:** `01-architecture.md` §1, §3, §5

## Job
Everything the feature views share, so they can be built in parallel without touching each other: the Vite app, routing,
layout and nav, the typed API client, the live-events hook, design tokens, UI primitives, the map base component, and PWA setup.

## Owns
`frontend/{package.json,vite.config.ts,index.html,tailwind.config.ts,tsconfig*.json}`, `frontend/src/main.tsx`,
`frontend/src/App.tsx`, `frontend/src/shared/**`, `frontend/public/**` (icons, manifest assets).

## Provides (`frontend/src/shared/`)
```ts
api-types.ts             // GENERATED by `npm run gen:api`. Never hand-edit
api.ts                   // typed fetch wrappers for every route in 02-contracts §4, e.g.
                         //   getCases(params): Promise<Case[]>, approveAction(id, by): Promise<ActionPlan>
queries.ts               // TanStack Query hooks: useCases, useCase(id), useKpis, useResources, useBuildings,
                         //   useActions, useGraph, usePredictions, useChains, useUnreached, useDemoStatus,
                         //   useWorkorders, useAdjusters, useMessages(partyId), useHelpCard(token), useFieldView(adjusterId),
                         //   useTimeline, useImpact, useMessagingStatus
useEvents.ts             // one EventSource('/api/events') for the app; maps event type → query keys to invalidate:
                         //   case.* → ['cases'], ['case', id], ['unreached'], ['kpis'] · message.* → ['messages'], ['case', id]
                         //   node.changed|prediction.updated → ['graph'], ['predictions'], ['chains'], ['buildings'], ['resources']
                         //   action.*|workorder.* → ['actions'], ['workorders'], ['buildings'] · resource.*|reservation.* → ['resources'], ['case', id]
                         //   kpis.updated → setQueryData(['kpis']) · clock.tick|demo.state → ['demoStatus'] (throttle 1/s)
                         //   also exposes a ring buffer of the last 200 events for the demo console log
format.ts                // money(cents), minutes→"3h 40m", simMinute→clock string, tierColor(tier)
tokens.css / tailwind    // design tokens: tiers P1 red-600, P2 orange-500, P3 amber-400, P4 slate-400;
                         //   node states ok green, at_risk amber, on_backup violet, failed red, restored teal;
                         //   State Farm accent red, CBRE accent green. Light + dark
ui/                      // shadcn/ui: button, card, badge, table, tabs, sheet (drawer), dialog, tooltip, progress, scroll-area
map/BaseMap.tsx          // MapLibre map (react-map-gl/maplibre), props {center, zoom, children}, style URL from env
                         //   VITE_MAP_STYLE (VERIFY default: OpenFreeMap liberty; fallback Carto Positron)
map/layers.tsx           // reusable layers: <PointsLayer data color radius onClick/>, <FeederOutageLayer/>, <SitesLayer/>
```

## App routes (`App.tsx`, lazy-load each module's default export, so feature tasks never edit this file)
| Path | Module | Layout |
|---|---|---|
| `/` → redirect `/command` | | |
| `/command` | command-center | desktop shell |
| `/portfolio` | portfolio-view | desktop shell |
| `/combined` | command-center with `combined` prop (shows CBRE buildings + action alerts on the same map) | desktop shell |
| `/demo` | demo-console | desktop shell |
| `/h/:token` | mobile-pwa `HelpCard` | bare mobile layout |
| `/field/:adjusterId` | mobile-pwa `FieldView` | bare mobile layout |

Desktop shell: top bar with the product name, view switcher (**State Farm | CBRE | Combined**, from the teammates' "isolate or
combine" idea), the sim clock (`useDemoStatus`, e.g. "Sun Feb 14 · 21:35 · ▶ 5×"), weather chip, messaging/LLM mode chips.
Responsive down to tablet. Mobile routes have no shell.

## PWA
`vite-plugin-pwa`: manifest name "Lifeline", short name "Lifeline", theme color, icons 192/512, `display: standalone`,
`start_url: "/"`. Scope covers `/h/*` and `/field/*`, so "Add to Home Screen" works from the help card or the field view.
Network-first caching for `/api/*` (fresh data matters more than offline use).

## Vite config
Dev server proxy `/api` → `http://localhost:8000` (including SSE: `ws: false`, no buffering). `npm run gen:api` script =
`openapi-typescript http://localhost:8000/openapi.json -o src/shared/api-types.ts`.

## Acceptance
- `npm run dev` shows the shell with the nav and a working route for every path (placeholder pages are fine until modules land).
- `useEvents` reconnects automatically after the backend restarts. Query invalidation is visible in React Query devtools.
- `npm run build` succeeds. Lighthouse "installable" passes for `/h/test`.

## Not in scope
Auth, i18n of the operator UI (customer texts are multilingual, the dashboards are English), complex state libraries.
